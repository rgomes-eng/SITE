## 8. INSTRUÇÕES DE USO

### 👨‍💻 Para Desenvolvedores
```bash
# Clonar repositório
git clone https://github.com/rgomes-eng/SITE.git

# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Deploy para Vercel
vercel --prod
```

### 🔧 Para Configuração
1. Copiar `.env.example` para `.env.local`
2. Configurar variáveis do Supabase
3. Configurar variáveis do site
4. Rodar `npm run dev`

### 📱 Para Deploy
1. Configurar variáveis de produção
2. Rodar `npm run build`
3. Deploy com Vercel CLI
4. Configurar DNS
